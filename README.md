# Hệ thống tự động hóa kiểm thử và triển khai phần mềm

## 1. Giới thiệu
Đây là đồ án Java xây dựng hệ thống hỗ trợ quản lý quy trình tự động hóa kiểm thử và triển khai phần mềm (CI/CD).

## 2. Công nghệ sử dụng
- Ngôn ngữ: Java
- IDE: Apache NetBeans 12.5
- Công cụ quản lý thư viện: Maven
- Giao diện: Java Swing
- Cơ sở dữ liệu: SQLite

## 3. Chức năng chính
- Đăng nhập và quản lý tài khoản.
- Quản lý dự án phần mềm.
- Quản lý pipeline kiểm thử và triển khai.
- Theo dõi quá trình chạy pipeline và trạng thái các bước.
- Xem lịch sử thực thi.
- Quản lý cấu hình và phân quyền người dùng.

## 4. Cách chạy chương trình
1. Cài đặt JDK tương thích.
2. Mở project bằng NetBeans.
3. Đợi Maven tải các thư viện cần thiết.
4. Build và chạy project từ NetBeans.

## 5. Tác giả
Đồ án môn học – Hệ thống tự động hóa kiểm thử và triển khai phần mềm.
